# MIT-6.006-Introduction to Algorithm(算法导论)-2020-Spring
I create this repository to record my learning process. Now you can see I introduce in English, but all files committed use Chinese as its language. So, if you are worried about language barrier but want to learn something about algorithm, I think this repository is very suitable for you.
(By the way: Some of practice is generated by GPT-5.6Sol or Claude-Opus5. I think they are high-quelity and even use AI mentioned above to support my final exam review.)

我创建这个仓库是为了记录我的学习过程。目前你看到的介绍是英文的，但所有提交的文件都使用中文。因此，如果你担心语言障碍，又想学习一些算法知识，我认为这个仓库非常适合你。（顺便说一下：部分练习内容由GPT-5.6Sol或Claude-Opus5生成，我认为它们质量很高，甚至用了上述AI来辅助我的期末复习）
